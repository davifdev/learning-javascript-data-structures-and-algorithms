# Listas duplamente ligadas

A diferença entre uma lista duplamente ligada e uma lista ligada comum é que, em uma lista ligada comum fazemos a ligação somente de um nó para o próximo, enquanto uma lista duplamente ligada temos uma ligação dupla, uma para o próximo elemento e outra para o elemento anterior.

A lista duplamente ligada nos oferece duas maneiras de iterar por ela: do início para o fim ou vice-versa. Também podemos acessar o próximo elemento ou o elemento anterior de um nó em particular.

Na lista ligada simples, quando iteramos pela lista e ultrapassamos o elemento desejado, é necessário retornar ao início da lista e reiniciar a iteração. Essa é uma das vantagens da lista duplamente ligada.
